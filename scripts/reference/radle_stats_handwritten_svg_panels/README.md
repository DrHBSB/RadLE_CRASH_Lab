# RadLE Stats Handwritten SVG Reference

This folder is a reference-only copy of the older handwritten SVG panel generator from:

`C:\Users\thehb\Documents\RadLE Stats\outputs\Data visualization\Handwritten SVG Panels`

It is kept for visual grammar, typography, panel layout, and style reference while RadLE v2 uses its own generator:

`scripts/make_radle_v2_handwritten_svg_panels.py`

Do not wire these files into the RadLE v2 pipeline. If RadLE v2 panels need style changes, patch the RadLE v2 generator and rerun the RadLE v2 build/audit flow.

- `make_handwritten_svg_panels.py`
- `make_handwritten_svg_panels_fixed.py`
- `font_sizes.csv`
